# Spark Electric — أبو تيم الكهربائي

Business website for an electrician in Makkah.

**Live Demo:** [spark-electric.saqaf-alshuabi.workers.dev](https://spark-electric.saqaf-alshuabi.workers.dev)

---

## 🛠️ Tech Stack

* **Framework:** Nuxt 4 (Vue 3 + TypeScript)
* **Styling:** Tailwind CSS
* **Deployment:** Cloudflare Workers / Pages
* **Package Manager:** pnpm

---

## ✨ Features

* 📱 **Responsive & Mobile-First:** Full-bleed hero section and tailored mobile navigation bar.
* 🌐 **Arabic RTL Support:** Native right-to-left layout design.
* 📞 **Direct Contact CTAs:** Integrated One-click Call & WhatsApp actions.
* ⚡ **Performance & SEO Focused:** Optimized meta tags, fast image loading, and smooth scrolling with Lenis.

---

## 🚀 Getting Started

### Prerequisites
Make sure you have [pnpm](https://pnpm.io/) installed.

### Installation & Development

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Deploy to Cloudflare
pnpm deploy
